📊 Langkah 1: Masukkan URL Google Apps Script

Tempelkan URL Web App dari Google Apps Script di bawah ini. Data nilai siswa akan otomatis terkirim ke Spreadsheet Anda.

Langkah 2: Cara Setup Google Spreadsheet

1. Buat Google Spreadsheet baru di sheets.google.com

2. Tambahkan header di baris 1: Tanggal | Nama | Nilai | Benar | Salah

3. Klik menu Extensions → Apps Script

4. Hapus semua kode, lalu tempel kode berikut:

function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  sheet.appendRow([
    new Date(),
    data.nama,
    data.nilai,
    data.benar,
    data.salah
  ]);
  return ContentService.createTextOutput(
    JSON.stringify({status: "sukses"})
  ).setMimeType(ContentService.MimeType.JSON);
}

5. Klik tombol Deploy → New Deployment

6. Pilih tipe: Web app

7. Set "Execute as" = Me, "Who has access" = Anyone

8. Klik Deploy, lalu salin URL yang muncul

9. Kembali ke halaman ini, tempel URL di kolom atas, klik 💾 Simpan URL

10. Selesai! Nilai siswa akan otomatis masuk ke Spreadsheet Anda ✅

📊 URL Google Apps Script

Tempelkan URL Web App dari Google Apps Script di bawah ini. Data nilai siswa akan otomatis terkirim ke Spreadsheet Anda.

📋 Cara Setup Google Spreadsheet

Langkah 1: Buat Google Spreadsheet baru

Langkah 2: Tambahkan header: Tanggal | Nama | Nilai | Benar | Salah

Langkah 3: Klik Extensions → Apps Script

Langkah 4: Tempel kode berikut:

function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  sheet.appendRow([
    new Date(),
    data.nama,
    data.nilai,
    data.benar,
    data.salah
  ]);
  return ContentService.createTextOutput(
    JSON.stringify({status: "sukses"})
  ).setMimeType(ContentService.MimeType.JSON);
}

Langkah 5: Klik Deploy → New Deployment → Web App

Langkah 6: Set "Who has access" = Anyone, lalu Deploy

Langkah 7: Salin URL dan tempel di kolom atas ↑
